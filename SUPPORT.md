# Support

## Check the README First

Before asking for help, please read [README.md](README.md) (or
[README-CN.md](README-CN.md)) for installation prerequisites, usage guidance,
and troubleshooting notes.

## Still Need Help?

- **Found a bug?** Open an issue using the *Bug Report* template:
  [Issues](https://github.com/OsmiumRemote/Osmium/issues/new/choose)
  Please make sure you are on the latest version first.
- **Have a suggestion or feature request?** Use the *Suggestions & Feature
  Requests* template on the same page.
- **Need to contact the maintainer directly?** Reach out on
  [Telegram](https://t.me/codecubist).

## Security Issues

Do not report security vulnerabilities through public issues. See
[SECURITY.md](SECURITY.md) instead.
